# Evidencias do ensaio controlado

Arquivos gerados por `scripts/benchmark_image_preparation.py` em fotos revisadas
TACO. Origem e anotacoes: `../datasets/taco_v1/`. Credito: Pedro F. Proenca e
Pedro Simoes, TACO, 2020. Base declarada CC BY 4.0.

A imagem comparativa e derivada de uma foto TACO: redimensionamento proporcional,
ruido sintetico e mediana seletiva. O manifesto nos relatorios identifica o
arquivo e seu hash. Esses resultados nao sao metricas de reconhecimento.
